## Modelo de negocio (nueva lógica)

3 tiers de cliente. Construimos plataforma como si todo cliente tuviera **Restaurante+** (todo desbloqueado). Después aplicamos restricciones por tier.

| Tier | Incluye |
|---|---|
| **Gratis** | Solo catálogo público (sin pedidos) |
| **Restaurante** | Catálogo + 1 sucursal + pedidos + analíticas + reseñas |
| **Restaurante+** | Todo lo anterior + reservas + fidelización + features avanzados |

Estrategia: feature flags / gates por tier al final, no durante desarrollo.
